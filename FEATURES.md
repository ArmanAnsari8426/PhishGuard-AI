## 🛠️ API Endpoints Summary

### Authentication
```
POST /api/register          - Create account
POST /api/login             - Get JWT token
POST /api/logout            - Invalidate token
POST /api/refresh           - Refresh token
```

### Scanning
```
POST /api/scan              - Scan single URL
POST /api/scan/batch        - Scan multiple URLs
GET  /api/scan/:id          - Get scan result
GET  /api/history           - Get scan history
DELETE /api/history/:id     - Delete scan
```

### Reports
```
GET  /api/report/:id        - Get PDF report
GET  /api/report/:id/pdf    - Download PDF
POST /api/report/generate   - Generate report
```

### User
```
GET  /api/user/profile      - Get profile
PUT  /api/user/profile      - Update profile
GET  /api/user/stats        - Get statistics
PUT  /api/user/settings     - Update settings
```

### Teams
```
POST /api/teams             - Create team
GET  /api/teams             - Get user teams
GET  /api/teams/:id         - Get team details
POST /api/teams/:id/invite  - Invite member
DELETE /api/teams/:id/members/:uid - Remove member
```

### Monitoring
```
POST /api/monitor/domain    - Add domain monitor
GET  /api/monitor/domains   - Get monitored domains
DELETE /api/monitor/:id     - Remove monitor
GET  /api/monitor/alerts    - Get alerts
```

### Webhooks
```
POST /api/webhooks          - Create webhook
GET  /api/webhooks          - List webhooks
PUT  /api/webhooks/:id      - Update webhook
DELETE /api/webhooks/:id    - Delete webhook
POST /api/webhooks/:id/test - Test webhook
```

### Admin
```
GET  /api/admin/users       - List users
DELETE /api/admin/users/:id - Delete user
GET  /api/admin/scans       - List all scans
POST /api/admin/block       - Block domain
GET  /api/admin/stats       - Admin statistics
```
